# openGym contribution screenshots

Screenshots for reviewing the shared-exercise, Apple Health and Apple Watch contributions.
All profiles and sessions shown are sample data. Images are kept in this documentation branch
so the feature branches do not carry presentation assets.

Shared-exercise screenshots were captured in Chromium using the contributed frontend and
an isolated local API with test accounts.

Apple Watch screenshots come from the contributed native Watch app on the watchOS Simulator.
Its cached routine and session were populated with sample data. Heart rate and energy shown
are simulator placeholders; these captures do not represent measured workout metrics.
